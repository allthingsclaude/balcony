1. ENCRYPTION FUNCTIONALITY

   Balcony establishes an end-to-end encrypted channel between a paired
   macOS host and an iOS client in order to transport Claude Code session
   data (terminal output and transcripts). The application implements the
   following standard, published cryptographic algorithms by way of the
   libsodium library:

     - X25519 (Curve25519) for Diffie-Hellman key agreement
         (IETF RFC 7748)
     - XChaCha20-Poly1305, 256-bit, for authenticated symmetric encryption
         (IETF RFC 8439 and draft-irtf-cfrg-xchacha)

   These are standard algorithms accepted by international standards bodies.
   The application does NOT implement proprietary or non-standard
   cryptography, and does NOT expose an open cryptographic interface.
